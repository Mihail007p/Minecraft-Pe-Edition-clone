# Minecraft PE Edition Clone

Воксельная песочница в духе **Minecraft Pocket Edition / Bedrock**, написанная на
TypeScript + Three.js. Запускается в браузере телефона (PWA, тач-управление),
а также на компьютере (клавиатура + мышь).

> Все текстуры и арты — собственные, генерируются процедурно кодом.
> Оригинальные ассеты Mojang не используются.

## Что уже есть (v0.1 — базовая версия)

- 🌍 **Бесконечный процедурный мир**: континенты и океаны, холмы и горы, пляжи,
  пещеры, руда (уголь, железо), биомы — равнины, лес, пустыня, тайга, горы, океан.
- 🌳 Деревья (дуб, ель), трава, цветы, кактусы; вода с прозрачностью и эффектом под водой.
- 🧱 **40+ блоков** в креативном инвентаре: камень, дерево, стекло, кирпичи, шерсть 12 цветов, TNT, верстак и др.
- 🎮 **Управление как в PE**: плавающий джойстик слева, свайп камеры справа,
  тап — поставить блок, удержание — сломать, кнопка прыжка, двойное нажатие — полёт,
  автопрыжок на блоки высотой 1.
- ⌨️ На ПК: WASD, пробел, Shift, Ctrl — бег, ЛКМ/ПКМ, колесо/цифры — хотбар, E — инвентарь,
  F или двойной пробел — полёт, Esc — пауза.
- 🎨 Рендер: отсечение невидимых граней, вершинное ambient occlusion, сглаженное
  освещение, туман, пиксельные облака, массив текстур с мипмапами (без «швов»).
- ⚙️ Настройки (сохраняются): дальность прорисовки, FOV, чувствительность,
  автопрыжок, инверсия Y, координаты/FPS.
- 📱 PWA: манифест, иконки, офлайн-кэш через service worker — можно «Добавить на главный экран».

## Запуск

```bash
npm install
npm run dev        # dev-сервер с HMR: http://localhost:5173
npm run build      # проверка типов + продакшен-сборка в dist/
npm run preview    # раздача dist/ (http://localhost:4173)
npm test           # тесты генерации, физики, мешера и дымовые тесты UI (Node, без браузера)
```

Чтобы открыть на телефоне в той же сети — зайдите по адресу `http://<IP компьютера>:5173`.

## Структура проекта

```
src/
├── main.ts                 — точка входа, регистрация service worker
├── config.ts               — все игровые константы и настройки по умолчанию
├── core/
│   ├── Game.ts             — состояние игры, игровой цикл, взаимодействие с блоками
│   └── Settings.ts         — настройки + localStorage
├── world/                  — чистая логика без three.js (тестируется в Node)
│   ├── Blocks.ts           — реестр блоков и их свойств
│   ├── Chunk.ts            — данные чанка 16×96×16 (Uint8Array)
│   ├── World.ts            — хранилище чанков, очередь генерации, get/setBlock
│   ├── WorldGen.ts         — рельеф, биомы, пещеры, руда, деревья
│   ├── Noise.ts            — simplex-шум, fBm, хеши, ГПСЧ с сидом
│   └── Raycast.ts          — выбор блока под прицелом (DDA)
├── render/
│   ├── textures.ts         — процедурные пиксель-арт текстуры 16×16
│   ├── TextureAtlas.ts     — DataArrayTexture (по слою на текстуру)
│   ├── ChunkMesher.ts      — построение геометрии: culling, AO, свет
│   ├── ChunkMaterial.ts    — шейдер блоков (sampler2DArray, туман, alpha-test)
│   ├── ChunkRenderer.ts    — меши чанков в сцене с бюджетом времени на кадр
│   ├── Sky.ts              — небо, туман, облака
│   └── BlockIcons.ts       — изометрические иконки блоков для UI
├── player/Player.ts        — AABB-физика, прыжки, плавание, полёт, автопрыжок
├── input/                  — TouchControls (PE-стиль), KeyboardMouse, общее состояние ввода
└── ui/                     — HUD, хотбар, инвентарь, меню, настройки, загрузка
tools/                      — генератор иконок PWA, рендер карты мира и листа текстур (для разработки)
tests/                      — node:test; дымовые тесты запускают игру целиком в jsdom + фиктивном WebGL
```

## Планы (следующие шаги)

- Сохранение миров на устройстве (IndexedDB), список миров.
- Генерация и мешинг в Web Worker, greedy meshing.
- Настоящее освещение (skylight/blocklight с распространением), факелы, день/ночь.
- Режим выживания: здоровье, голод, инструменты и скорость добычи, дроп блоков, крафт.
- Мобы, звуки, анимация руки/блока в руке, трещины при ломании.
- Сборка в APK через Capacitor.
